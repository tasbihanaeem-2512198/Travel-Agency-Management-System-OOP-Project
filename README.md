Travel Agency Management System

📌 Project Description
The Travel Agency Management System is a Java-based desktop application developed to automate and simplify travel agency operations. The system allows efficient management of customer records, travel bookings, hotel reservations, and payment details through an organized and user-friendly interface. It is developed using Object-Oriented Programming (OOP) concepts with SQL database integration for secure data management.

✨ Features
Customer Registration and Management
Travel Package Booking
Hotel Reservation Management
Ticket Booking System
Payment and Billing Records
Search, Update, and Delete Operations
Database Connectivity using JDBC

🛠️ Technologies Used
Java
SQL Database
JDBC
OOP Concepts
Apache NetBeans

▶️ Installation & Execution
Install Java JDK and SQL database server.
Open the project in Apache NetBeans.
Configure the database connection settings.
Import the SQL database file if provided.
Compile and run the project.

🎯 Project Objective
The main objective of this project is to provide a digital solution for managing travel agency operations efficiently while reducing manual work, improving data organization, and enhancing booking management.
